# IoT MVP Project

This project is a REST API microservice developed in Python using FastAPI.

## Features
- Receive sensor data
- Detect anomalies
- Store data in SQLite database
- Return alerts via API

## Technologies
- Python
- FastAPI
- Pydantic
- SQLite
